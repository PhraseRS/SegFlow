# pyside6-ui-development-rules Rules

## Purpose

Specific rules for PySide6 based UI development focusing on UI/UX excellence and performance.

## Best Practices

- Follow the guidelines consistently
- Apply rules during code review
- Use as reference when writing new code
- Use `Signal` / `Slot` (not `pyqtSignal` / `pyqtSlot`)
- Always set parent for QObject subclasses to prevent premature GC
